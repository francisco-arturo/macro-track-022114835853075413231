Security model

Locked at the row, not the screen.

  • 01

    Member rows. Every member-owned table carries member_id. Policies compare it to auth.uid() on select, insert, update and delete.

  • 02

    Admin rows. An is_admin() security-definer helper checks the caller's role without recursing through profiles.

  • 03

    Server only. The Anthropic key and service-role key stay in server environment variables. The browser gets the anon key and a session token.
